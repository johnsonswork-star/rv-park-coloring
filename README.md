# Color Camp: RV Park
Cozy paint-by-numbers for iPad. Coloring earns coins; coins decorate your RV park. Static PWA (no build): index.html, style.css, scenes.js (procedural pages), game.js, sw.js. Progress in localStorage key `rvpark-v1`.
Deployed copy: https://johnsonswork-star.github.io/rv-park-coloring/ (public repo johnsonswork-star/rv-park-coloring).

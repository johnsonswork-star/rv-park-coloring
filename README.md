# Cozy Camp (v4)
Cozy match-3 + paint-by-numbers for iPad. Match pieces to paint a line-art scene with watercolor fills; finishing earns coins to decorate your RV park. Static PWA, no build: index.html, style.css, art.js (pieces + scene), park.js (park art), game.js, sw.js, bundled Fredoka font. Progress in localStorage key `cozycamp-v2`. v1 (pixel coloring) is in git history.
Live: https://johnsonswork-star.github.io/rv-park-coloring/
